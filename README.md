# 俄罗斯方块拖拽版游戏

一款纯HTML静态页面实现的俄罗斯方块拖拽版游戏，支持移动端手指拖拽操作。

## 本地运行

直接双击 `frontend-fortune/index.html` 即可在浏览器中打开游玩。

## Docker部署

```bash
docker-compose up -d
```

访问 http://服务器IP:8081 即可游玩。

## 游戏规则

1. **拖拽放置**：从底部待选区拖动方块到游戏面板中
2. **放置检测**：方块不能与已有方块重叠，不能超出边界
3. **行清除**：填满一行自动消除，获得分数
4. **得分规则**：清除1行+1分，同时清除N行+N²分
5. **游戏结束**：当3个待选方块都无法放置时游戏结束

## 操作指南

- **移动端**：手指按住方块拖动到目标位置
- **桌面端**：鼠标按住方块拖动到目标位置
- 放置成功方块固定，放置失败方块返回原位
- 3个待选方块全部放置后自动生成新方块
